A API do Need Alert permite que o sistema do seu negócio faça, sem ninguém na frente da tela, o que hoje você faz pelo painel.

## O que estará disponível

- **Chaves de API** criadas pelo dono da rede no painel, com nome, unidades permitidas e permissões. A chave é exibida uma única vez e pode ser trocada ou revogada a qualquer momento.
- **Itens:** listar, criar, editar e arquivar, com uma **referência externa** para usar o código do seu sistema (como o SKU), e obter o QR Code.
- **Disparos:** estimar o custo, disparar na hora ou agendar, acompanhar o status, reagendar e cancelar.
- **Créditos:** consultar saldo e extrato.
- **Idempotência:** um header `Idempotency-Key` para que uma nova tentativa após uma falha de rede não dispare o alerta duas vezes.

Todo disparo pela API segue as mesmas regras do painel: o custo é calculado antes, o saldo é conferido e o débito é de 1 crédito por pessoa avisada.
