The Need Alert API lets your business system do, with no one at the screen, what you do today in the dashboard.

## What it's for

## What will be available

- **API keys** created by the chain owner in the dashboard, with a name, allowed units, and permissions. The key is shown only once and can be rotated or revoked at any time.
- **Items:** list, create, edit, and archive, with an **external reference** so you can use your own system's code (such as the SKU), and get the QR code.
- **Dispatches:** estimate the cost, send now or schedule, track the status, reschedule, and cancel.
- **Credits:** check the balance and statement.
- **Idempotency:** an `Idempotency-Key` header so a retry after a network failure doesn't send the alert twice.

Every dispatch through the API follows the same rules as the dashboard: the cost is calculated first, the balance is checked, and the charge is 1 credit per person notified.
